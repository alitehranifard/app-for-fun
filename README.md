# Heavy Talks

A focused Windows desktop app that presents one positive, disciplined thought at a time.

## Run it

Double-click **Launch Heavy Talks.bat**.

## Controls

- Click **New thought** or press `Space` for another quote.
- Click **Copy quote** or press `Ctrl+C` to copy the current quote.

The app uses native Windows PowerShell and WPF, so there is nothing to install.
